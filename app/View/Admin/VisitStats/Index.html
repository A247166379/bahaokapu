访问来源统计说明

来源统计根据浏览器提供的来源信息记录。直接访问、收藏夹，以及浏览器或应用未提供来源信息的访问，归入“直接访问 / 未提供来源”，不能据此判断访客一定是直接输入网址。

来源在 30 分钟内沿用；站内点击和刷新保留原来源，新的外部来源可更新归因。浏览器通常不提供搜索关键词，本统计不记录关键词。

两张表的 PV 占比均按所选日期已记录来源的总 PV 计算。仅有来源网站域名的记录进入“来源网站”表，域名占比相加可能不足 100%。同一浏览器可能出现在多个来源中，各来源 UV 相加可能超过来源总 UV。

来源统计的开始时间可能与访问量统计不同，启用前或暂停期间的访问来源无法补回。

访问统计说明

全部日期与小时按北京时间（Asia/Shanghai）汇总。PV 为页面浏览次数；UV 为当天去重的匿名浏览器数，同一个人使用不同设备、浏览器或清除浏览器标识后可能被分别计数。

统计从启用后开始记录，启用前的历史没有数据。设备、国家和小时的 UV 分别去重，分组 UV 相加可能超过整日 UV。

本统计按访问 IP 离线识别国家与地区，仅保存识别结果，不保存原始 IP。代理或 VPN 可能影响地区识别。
